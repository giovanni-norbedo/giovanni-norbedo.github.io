A summary of the operating system, terminal workflow, code editors, languages, and software tools I use on a daily basis.

1.

Operating System & Desktop

My primary workstation runs Arch Linux with the Linux Zen Kernel.

For window management, I use Qtile WM configured in Python, keeping the same keybindings and workspace navigation I used on bspwm for years. Application launching is handled by Rofi, window compositing by Picom, and notifications by Dunst.

2.

Terminal & Shell

The terminal is my primary workspace. I use Kitty with GPU accelerated rendering, an OLED true black palette, and JetBrains Mono Nerd Font.

My interactive shell is Zsh inside tmux for session persistence. The prompt is powered by Starship for Git status and runtime information. Directory navigation is handled by zoxide, fuzzy completions by fzf-tab, and shell history recall by atuin.

3.

Code Editors & Documents

I divide editing between Neovim and VS Code. The first one is my go-to for terminal workflows, scripting, and remote servers. The second one is for large projects and debugging.

I am currently learning formal proofs in Lean 4, working in Neovim via lean.nvim. For document preparation, I use Typst for fast compilation alongside TeXpresso for live interactive LaTeX rendering.

4.

Languages & Frameworks

  • Python (3.14 / uv): PyTorch, NumPy, and scientific computing, managed with uv.
  • C/C++ & OpenMP: Parallel computing and performance critical algorithms.
  • Web Development: Django, FastAPI, Node.js, React, TypeScript, and HTML/CSS.
  • R: Statistical inference and data analysis.
  • Currently Learning: Rust for systems programming and Lean 4 for interactive theorem proving.
5.

Notes & Mobile Setup

For notes, I use Obsidian (Markdown with KaTeX) organized via Zettelkasten. Research papers are managed in Zotero with BibTeX export, and PDFs are read in Zathura with Synctex support.

On mobile, I use an Android phone debloated with adb to keep only essential apps. Offline, I regularly play chess.

6.

Music & Listening

For focus during work, I listen to 1990s trip hop, Bristol sound, downtempo, and abstract electronic music. Key artists include Handsome Boy Modeling School, Massive Attack, Portishead, DJ Shadow, Bonobo, UNKLE, and Tricky. I also occasionally sketch beats in LMMS.
