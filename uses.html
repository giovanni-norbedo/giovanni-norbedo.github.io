A summary of the operating system, terminal workflow, code editors, languages, and software tools I use on a daily basis. After trying everything there is...

Here are my [dotfiles].

OS + DE

Having finally said goodbye to my trusty debian after years of unwavering loyalty, my primary workstation runs arch linux with the linux zen kernel. For window management, I use qtile wm configured in Python (while the entire linux community moved on to flashy animations on hyprland), keeping the same keybindings and workspace navigation I used on bspwm for years. Application launching is handled by rofi, window compositing by picom, and notifications by dunst.

The entire system follows an OLED aesthetic. I also built a togglable, system-wide E-ink mode via custom GLSL shaders: with a single keybinding, the whole desktop transforms into a paper-like, monochrome display that is much easier on the eyes for long reading sessions (and very fun to show off).

The terminal is my primary workspace. I use kitty with JetBrains Mono Nerd Font. My interactive shell is zsh and the prompt is powered by starship for git status and runtime information. I use various, sparkling Rust programs to replace traditional command-line utilities, because if a 50 year old rock-solid unix utility hasn't been rewritten in Rust this year, is it even safe to touch?

Code

I use both neovim and VS Code for editing. I utilize the first one for various purposes, including scripting and terminal workflows. The second one is for big projects and debugging. Positron is my preferred tool for creating R markdown or Python notebooks.

For document preparation, I use Typst for fast compilation alongside TeXpresso for live interactive LaTeX rendering. But plain markdown is still my best friend.

Stack

Python: PyTorch, NumPy, and scientific computing, managed with uv.
C/C++ & OpenMP: Parallel computing and performance critical algorithms.
Web: Django, FastAPI, Node.js, React, HTML/CSS (and so on).
R: Statistical inference and data analysis.
Currently learning: Rust for systems programming, Lean 4 for theorem proving, Haskell for fun.
Everything else: Solid foundations across networking, security, databases and various stacks. Comfortable picking up any tool or library on the fly.

Other

For notes, I use Obsidian (markdown with KaTeX) organized via zettelkasten. Research papers are managed in Zotero with BibTeX export, and pdfs are read in zathura.

On mobile, I use an android phone debloated with adb to keep only essential apps. Offline, I regularly play chess and poker, read books, hang out with close friends, and hit the gym.

For focus during work, I listen to 1990s trip hop, Bristol sound, downtempo, and abstract electronic music. Key artists include Handsome Boy Modeling School, Massive Attack, Portishead, DJ Shadow, Bonobo, UNKLE, and Tricky. I also occasionally sketch beats in LMMS.
