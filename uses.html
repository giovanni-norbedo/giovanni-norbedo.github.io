1.

Operating System & Desktop

Having finally said goodbye to my trusty Debian after years of unwavering loyalty, my primary workstation runs Arch Linux with the Linux Zen Kernel.

For window management, I use Qtile WM configured in Python (while the entire Linux community moved on to flashy animations on Hyprland), keeping the same keybindings and workspace navigation I used on bspwm for years. Application launching is handled by Rofi, window compositing by Picom, and notifications by Dunst.

2.

Terminal & Shell

The terminal is my primary workspace. I use Kitty, an OLED true black palette, and JetBrains Mono Nerd Font.

I also built a togglable E-ink mode, because I like the “book” feel and because it's easier on the eyes (and also because it's fun to show off to friends).

My interactive shell is Zsh inside tmux for session persistence. The prompt is powered by Starship for Git status and runtime information. I use various, sparkling Rust programs to replace traditional command-line utilities, because if a 50 year old rock-solid Unix utility hasn't been rewritten in Rust this year, is it even safe to touch?

3.

Code Editors & Documents

I use both Neovim and VS Code for editing. I utilize the first one for various purposes, including scripting and terminal workflows. The second one is for big projects and debugging. Positron is my preferred tool for creating R Markdown or Python notebooks.

For document preparation, I use Typst for fast compilation alongside TeXpresso for live interactive LaTeX rendering. But plain Markdown is still my best friend.

4.

Languages & Frameworks

  • Python: PyTorch, NumPy, and scientific computing, managed with uv.
  • C/C++ & OpenMP: Parallel computing and performance critical algorithms.
  • Web development: Django, FastAPI, Node.js, React, and HTML/CSS.
  • R: Statistical inference and data analysis.
  • Currently learning:Rust for systems programming and Lean 4 for interactive theorem proving.
5.

Notes & Mobile Setup

For notes, I use Obsidian (Markdown with KaTeX) organized via Zettelkasten. Research papers are managed in Zotero with BibTeX export, and PDFs are read in Zathura.

On mobile, I use an Android phone debloated with adb to keep only essential apps. Offline, I regularly play chess.

6.

Music & Listening

For focus during work, I listen to 1990s trip hop, Bristol sound, downtempo, and abstract electronic music. Key artists include Handsome Boy Modeling School, Massive Attack, Portishead, DJ Shadow, Bonobo, UNKLE, and Tricky. I also occasionally sketch beats in LMMS.
